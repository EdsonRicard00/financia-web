🚀 financIA | O Futuro da Análise Quantitativa
📌 Visão Executiva (The Pitch)
O mercado financeiro sempre operou como uma "caixa preta" acessível apenas a investidores institucionais. O financIA nasce para democratizar o acesso a análises quantitativas de alta precisão. Projetado com uma arquitetura escalável e uma interface de usuário (UI/UX) imersiva, a plataforma traduz modelos complexos de Deep Learning em insights acionáveis para investidores de todos os níveis.
Decisões baseadas em algoritmos, não em emoções.
✨ Proposta de Valor e UX Design
Como consultoria de tecnologia e produto, entendemos que poder computacional sem usabilidade é inútil. O financIA foi construído sob rigorosos princípios de User Experience (UX):
Design Cognitivo: Interface Dark Mode de alto contraste, reduzindo a fadiga visual e destacando dados críticos (vermelho/verde) para tomada de decisão em milissegundos.
Fricção Zero: Jornada do usuário otimizada. Do acesso à plataforma até a visualização do veredito da IA, o fluxo é contínuo, dinâmico e responsivo.
Microinterações: Feedback visual em tempo real (ex: Conexão Neural: ATIVA) para construir confiança entre o usuário e o modelo preditivo.
⚙️ Funcionalidades Core (Enterprise Features)
🧠 Motor de Deep Learning: Algoritmos proprietários que analisam o histórico e a volatilidade para gerar o "Veredito financIA" (ex: COMPRA FORTE).
📊 Cobertura Global: Monitoramento contínuo de 500+ ativos financeiros (NASDAQ, B3, Criptomoedas).
📈 Análise Técnica Profunda: Gráficos interativos renderizados em tempo real, cruzando preço, volume e indicadores técnicos avançados.
📰 Feed de Sentimento de Mercado: Integração de notícias em tempo real que impactam diretamente a volatilidade dos ativos analisados.
⚡ Alta Disponibilidade: Operação 24/7 com uma precisão histórica de modelos na casa dos 94%.
🏗️ Arquitetura Tecnológica
O sistema foi desenhado visando manutenibilidade, performance e escalabilidade, separando responsabilidades entre o motor de dados e a camada de apresentação.
Backend & Data Science: Python 3.x
Core Scripts: main.py, importar_csv.py, setup_db.py.
Gerenciamento de Dependências: Ambiente virtual rigorosamente controlado (requirements.txt).
Banco de Dados: Banco relacional otimizado (financas.db) para consultas de alta velocidade em séries temporais.
Frontend (UI/UX): HTML5, CSS3 (Animações e Design Responsivo via style.css), e JavaScript (script.js para reatividade do lado do cliente).
🚀 Como Executar o Projeto (Local Environment)
Para engenheiros e desenvolvedores que desejam compilar o terminal localmente:
Clone o repositório:
git clone https://github.com/seu-usuario/financia.git
cd financia


Configure o Ambiente Virtual:
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows


Instale as dependências:
pip install -r requirements.txt


Inicialize o Banco de Dados:
python setup_db.py
python importar_csv.py


Inicie o Servidor:
python main.py

Acesse http://127.0.0.1:8000/ no seu navegador.
